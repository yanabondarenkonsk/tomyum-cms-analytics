# TomYum — «Аналитика приложения»

Версия 1.1, 12 октября 2026. Комплект для обсуждения с разработчиком: интерфейс и требования к production-реализации.

## Открыть макет

Скачайте комплект и откройте `index.html` в современном браузере. Установка, сборка и сервер не нужны. Файл работает локально, не обращается к API и не загружает внешние библиотеки.

На GitHub исходный HTML отображается как код. Чтобы посмотреть интерфейс, скачайте файл и откройте его в браузере. Размещение в GitHub Pages — отдельная настройка, не выполнена этим комплектом.

## Что внутри

- `index.html` — единый интерактивный макет раздела.
- `CMS_Analytics_Spec.md` — итоговое ТЗ с формулами, источниками, экспортом, ID клиентов, сегментами, API и критериями приёмки.
- `REVIEW_NOTES.md` — проведённые проверки и ограничения макета.

## Сценарий обсуждения

1. Измените месяц/платформу/ресторан и проверьте обзор и заказы.
2. Откройте «Когорты и удержание», выберите ячейку. Переключите достигших/не достигших результата.
3. Найдите клиента по CRM ID и откройте его историю.
4. Отметьте клиентов либо выберите всех по фильтру. Сохраните в сегмент.
5. В «Сегментах клиентов» проверьте состав и действие «Открыть в рассылках». Здесь оно не отправляет сообщений.
6. Выгрузите настоящий XLSX с демоданными. Проверьте листы, ID и условия.
7. В конструкторе создайте сводку и добавьте её в «Мой дашборд».

## Что обязательно согласовать

Полные листы «События» и «Основные параметры» из исходного ТЗ отсутствуют в приложенном DOCX. Получить их до окончательной оценки интеграции. Подтвердить точный ID клиента CRM, серверные статусы оплаты и возвратов, связь корзины с заказом и интерфейс передачи сегмента в существующие рассылки.

Пуши уже внедрены: их SDK, отчёты, кампании и механизм отправки не входят в переработку. Аналитика готовит сегмент; отправка остаётся в существующем модуле.

В макете исключительно вымышленные записи. Подключение к рабочей CMS, персональные данные, сохранение на сервере и рассылки отсутствуют.
